# 시즌 1 〈구름을 집에 보내 주는 이야기〉 — 12화

> 공모전 제출용 스토리 정본. 기획서(②-3항)는 이 문서의 요약이다.
> **뼈대(무슨 일이 일어나는가)는 사람이 쓴다.** 모델이 맡는 건 그 뼈대를 오늘 이 길에 맞게 말하는 일뿐이다.

---

## 0. 설정

어느 아침, 창밖에 **조그만 구름 한 조각**이 따라온다. 길을 잃었다.
엄마 구름에게 돌아가려면 **충분히 커져서 떠오를 수 있어야** 한다.

> **구름은 아이가 창밖에서 찾아 준 것을 먹고 자란다.**

이 한 줄이 시즌 전체를 지탱한다. 왜냐하면:

| 설계 요구 | 이 설정이 푸는 방식 |
|---|---|
| 아이가 창밖을 봐야 한다 (멀미 완화) | 창밖을 봐야 구름이 자란다 — **시키는 말이 아니라 역할** |
| 진행이 눈에 보여야 한다 | 구름이 1화부터 12화까지 **점점 커진다** |
| 매 화에 작은 목표 | "오늘은 뭘 찾아 줄까" |
| 시즌에 큰 목표 | 구름을 하늘로 보낸다 |

**구름이 먹는 네 가지** — 전부 차창 밖에 실제로 있는 것이다.

| 먹이 | 길에서 오는 신호 |
|---|---|
| 물 | 강·다리·비·안개·세차 |
| 바람 | 터널·트인 길·속도 |
| 빛 | 아침해·노을·가로등·터널 끝 |
| 소리 | 기차·아이들·새·빗소리 |

## 0-1. 등장

| | |
|---|---|
| **아이** | 실제 아이 이름. 주인공. 유일하게 구름에게 먹이를 줄 수 있다 |
| **구름** | 동행. 말을 한다. 겁이 많고 잘 웃는다. 자랄수록 목소리가 낮아진다 |
| **탈것** | 차. 시즌 1은 바다 시즌이라 **배**. 1화에서 아이가 이름을 지어 준다 |
| **그림자** | 4화부터. 굴에 사는 친구. 빛을 무서워한다. 시즌의 갈등 |
| **엄마 구름** | 12화에만 나온다 |

## 0-2. 한 화의 모양

> **문제가 생긴다 → 아이가 할 일을 받는다 → 길에서 온 사건이 돕거나 방해한다 → 해결된다 → 다음 화 떡밥**

- **한 번의 주행 = 한 화.** 날짜가 아니라 **화 번호**가 진행을 정한다(주말에 안 타도 이야기는 안 밀린다).
- **길이는 남은 시간이 정한다.** 12분이면 핵심 3비트만, 65분이면 곁가지가 붙고 특별편이 된다.
- 길에서 안 온 사건은 **빠지는 게 아니라 다른 것으로 대체된다**(강이 없으면 비, 비도 없으면 안개).

---

## 1화 — 창틀에 앉은 손님
| | |
|---|---|
| **문제** | 구름이 길을 잃었다. 엄마한테 가려면 커져야 하는데 너무 작다 |
| **아이 할 일** | 배 이름 지어 주기 + 창밖에서 **반짝이는 것** 하나 찾아 주기 |
| **길이 하는 일** | 아침해(출발 시각) / 첫 신호 대기에서 "지금 창밖에 뭐가 보여?" |
| **해결** | 아이가 찾아 준 빛을 먹고 구름이 **아주 조금** 커진다 |
| **떡밥** | "구름이 목이 마르대. 내일은 물을 찾아 줄까?" |

## 2화 — 첫 물방울
| | |
|---|---|
| **문제** | 구름이 바싹 말랐다. 물을 못 먹으면 더 작아진다 |
| **아이 할 일** | 창밖에서 **물** 찾기 — 강·물웅덩이·비 |
| **길이 하는 일** | 다리를 건너면 "커다란 강!" · 비가 오면 그대로 · 둘 다 없으면 **세차 간판** |
| **해결** | 물을 먹고 구름이 통통해진다 |
| **떡밥** | "이제 떠오르려면 바람이 있어야 한대." |

## 3화 — 바람 한 줌
| | |
|---|---|
| **문제** | 구름이 떠오르질 않는다. 무겁다 |
| **아이 할 일** | **바람이 센 곳** 찾기 |
| **길이 하는 일** | 터널 = 바람 통로 · 트인 고가 · 속도가 붙는 구간 |
| **해결** | 터널을 지나며 바람을 먹고 구름이 **처음으로 창문 위까지 떠오른다** |
| **떡밥** | "그런데 굴 안이 깜깜했지? 구름이 무서웠대." |

## 4화 — 깜깜한 굴  ★그림자 등장
| | |
|---|---|
| **문제** | 또 그 굴이다. 구름이 안 들어가겠다고 버틴다 |
| **아이 할 일** | **노래 불러 주기** (굴을 지나는 동안만) |
| **길이 하는 일** | 터널 진입 → 통과 시간만큼 |
| **해결** | 아이 노래를 따라 들어간다. 굴 안에서 **누가 같이 따라 불렀다** |
| **떡밥** | "굴 안에서 누가 같이 노래했어. 누구였을까?" |

## 5화 — 숨소리
| | |
|---|---|
| **문제** | 굴에 누가 있다. 구름은 궁금하고 무섭다 |
| **아이 할 일** | 굴에서 **소리 듣기**(조용히 하기) |
| **길이 하는 일** | 같은 터널 — **앱이 몇 번째인지 안다** |
| **해결** | 숨소리를 들었다. 구름이 "무서운 애는 아닌 것 같아"라고 한다 |
| **떡밥** | "내일은 이름을 물어볼까?" |

## 6화 — 그림자가 따라 나왔다
| | |
|---|---|
| **문제** | 굴 밖으로 **그림자**가 따라 나왔다. 그런데 햇빛에 닿자 아파한다 |
| **아이 할 일** | 그림자가 숨을 **그늘** 찾아 주기 — 터널·고가 밑·가로수·큰 차 옆 |
| **길이 하는 일** | 그늘이 지는 구간 / 터널 / 건물 사이 |
| **해결** | 구름 **밑에** 숨으면 된다는 걸 알아낸다. 둘이 같이 간다 |
| **떡밥** | "근데 구름은 빛을 먹어야 크는데… 괜찮을까?" |

## 7화 — 빛을 누가 가질까  ★갈등 정점
| | |
|---|---|
| **문제** | 구름은 빛이 필요하고, 그림자는 빛이 싫다. **둘이 싸운다** |
| **아이 할 일** | 둘 다 되는 자리 찾기 — **빛과 그늘이 같이 있는 곳** |
| **길이 하는 일** | 가로수길(햇빛이 깜빡깜빡) · 터널 입구 · 구름 낀 하늘 |
| **해결** | 가로수길에서 빛이 **깜빡인다.** 구름은 먹고 그림자는 숨는다. 번갈아 가면 된다 |
| **떡밥** | "둘이 화해했어. 그런데 구름이 좀 이상해. 너무 무거워졌어." |

## 8화 — 비가 되어 버렸다  ★좌절
| | |
|---|---|
| **문제** | 구름이 너무 커져서 **비가 되어 쏟아졌다.** 다시 작아졌다 |
| **아이 할 일** | 울지 않기. 그리고 처음부터 다시 모아 주기 |
| **길이 하는 일** | 비·와이퍼·젖은 길 (비가 안 오면 "어제 비가 왔대"로 처리) |
| **해결** | 그림자가 말한다 — "내가 밑에서 받쳐 줄게. 이번엔 안 쏟아져." |
| **떡밥** | "혼자 크는 게 아니었나 봐." |

## 9화 — 길에서 만난 친구들
| | |
|---|---|
| **문제** | 혼자서는 다시 못 큰다. 도움이 필요하다 |
| **아이 할 일** | 창밖 친구들에게 **인사하기** |
| **길이 하는 일** | 숲(사슴) · 학교 앞(아이들) · 철길(기차) — 그날 실제로 지나는 것만 |
| **해결** | 사슴은 바람을, 아이들은 소리를, 기차는 김을 하나씩 준다 |
| **떡밥** | "거의 다 컸어! 이제 하늘에 닿을 수 있을까?" |

## 10화 — 하늘이 보인다
| | |
|---|---|
| **문제** | 구름이 거의 다 컸다. 그런데 **그림자는 하늘에 못 간다** |
| **아이 할 일** | 그림자에게 할 말 생각해 주기 |
| **길이 하는 일** | 트인 하늘·고가·긴 직선 구간 |
| **해결** | 안 된다. 그림자가 "먼저 가"라고 한다. 구름이 안 간다고 한다 |
| **떡밥** | "둘 다 가는 방법이 있을까? 내일 찾아보자." |

## 11화 — 구름 속에 숨기
| | |
|---|---|
| **문제** | 둘 다 가는 방법을 찾아야 한다 |
| **아이 할 일** | 그림자가 어디에 잘 숨는지 떠올리기 (6화 복습) |
| **길이 하는 일** | 터널 — **그 굴에 다시 들어간다.** 여기서 처음 만났다 |
| **해결** | **구름 속이 제일 어둡다.** 그림자가 구름 안으로 들어간다. 먹구름이 된다 |
| **떡밥** | "내일이야. 내일 하늘로 가." |

## 12화 — 하늘로  ★시즌 피날레
| | |
|---|---|
| **문제** | 마지막. 떠오를 수 있을까 |
| **아이 할 일** | 마지막 **빛 하나** 찾아 주기 + 손 흔들기 |
| **길이 하는 일** | 도착 직전 구간 전체 |
| **해결** | 구름이 그림자를 품고 떠오른다. **엄마 구름이 마중 나온다** |
| **작별** | "고맙다고 {아이}{이} 머리 위에 **그늘을 하나** 두고 갔대." |
| **다음 시즌** | 그 그늘이 더워질 때마다 따라다닌다 — **시즌 2 〈따라다니는 그늘〉** |

## 짧은 길 / 긴 길

| | 12분 (등하원) | 65분 (주말 나들이) |
|---|---|---|
| 비트 수 | 3~4 | 10~14 |
| 구성 | 문제 → 해결 → 떡밥 | 문제 → 시도 → 실패 → 친구 → 해결 → 떡밥 |
| 곁가지 | 없음 | 그날 길에서 온 것(사슴·휴게소·기차)이 한 장면씩 |
| 정체가 나면 | 떡밥을 하나 더 | **곁가지 한 화**를 끼워 넣는다 |

## 같은 길을 매일 가도 다른 이유

1. **화가 진행된다** — 오늘은 5화, 내일은 6화
2. **같은 곳에 기억이 쌓인다** — 그 터널이 4·5·6·11화에서 전부 다른 뜻이다
3. **그날 실제로 온 신호가 장면을 채운다** — 비 온 날의 8화와 맑은 날의 8화는 다르다

## 분량

| | 손으로 쓸 것 | 모델이 할 것 |
|---|---|---|
| 시즌 뼈대 12화 | **전부** (이 문서) | — |
| 화별 비트 3~14개 | 핵심 비트의 **뜻** | 그날 길·날씨·시각에 맞춘 **문장** |
| 반복 장소 변주 | 단계(1회/2~4회/5~9회/10회+) | 각 단계의 말투 |

**"무슨 일이 일어날지"는 끝까지 사람이 정한다.** 아이 콘텐츠에서 거기를 모델에 맡기면 안 된다.
