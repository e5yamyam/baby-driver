# 생성 문장 실측 — AI 가 실제로 쓴 323줄

2026-11-17 측정. 앱 안의 지시문(`StoryPrompt`)과 어린이 필터(`ChildFilter`)를 **코드 그대로**
쓰고, 생성만 차 밖의 모델에게 맡겨 본 기록이다.

## 왜 이 문서가 있나

Pleos 온디바이스 LLM 은 에뮬레이터에서 꺼져 있다(`on-device LLM is disabled`). 그래서 생성이
붙었다고만 말할 수 있고 **문장을 한 줄도 보여 줄 수 없었다.** 지시문이 쓸모 있는지, 필터가
멀쩡한 문장까지 막는지도 알 길이 없었다.

## 어떻게 쟀나

1. `GenProbeExportTest` — 실제 `StoryPrompt` 로 지시문 **323줄**을 꺼낸다(5세·3세 두 층)
2. `tools/gen_probe.py` — 그 지시문을 그대로 모델에게 보낸다
3. `GenFilterReportTest` — 받은 답을 **실제 `ChildFilter`** 에 통과시킨다

사람이 중간에서 문장을 손대는 자리는 없다. 아이 이름은 시연 프로필(`현차`)을 썼다.

**결과 — 323줄 중 323줄 통과(100%).**

⚠️ 차에서 도는 것은 **작은 온디바이스 모델**이다. 여기 쓴 모델은 그 대역의 대역배우일 뿐
   같은 모델이 아니다. 이 표가 말해 주는 것은 "지시문과 필터가 말이 되는가" 까지다.

## 이 측정으로 고친 것

### 1. 지시문에서 "한 문장만" 을 뺐다
원고의 한 쪽은 대개 **두 문장**이다("깜깜한 굴이에요. 그림자가 벌떡 일어났어요.").
"한 문장" 을 요구하니 모델이 둘을 **쉼표로 이어 붙여** 늘였고, 그림책의 짧게 끊는 결이
통째로 사라졌다. 문장 수를 원문에 맞추고 글자 수에 천장을 주자 마침표로 끊어 쓴다.

### 2. 길이 천장을 좁혔다
원문의 2배까지 봐 주던 것을 **원문+20자**로 줄였다. 길이가 결이다.

### 3. "문장이 늘면 막는다" 는 규칙은 넣었다가 뺐다
첫 측정에서 막힌 4줄이 전부 그거였는데, 넷 다 모델이 **긴 문장을 짧게 쪼갠 것**이었다.
그림책에서는 그게 더 나은 글이다. **결은 지시문이 끌고, 안전만 필터가 막는다.**

### 4. 금지어를 한 글자로 쓰지 않는다
`"죽"` 하나를 막으니 **"입을 삐죽 내밀었어요"** 가 걸렸다 — 그건 원고에 있는 문장이다.
`"총"` 은 "총총", `"사고"` 는 "사고 싶어", `"피가"` 는 "커피가" 를 잡는다.
필터가 원고의 말을 막기 시작하면 **생성 기능이 조용히 죽는다**(전부 내장 문장으로 돌아서
겉으로는 멀쩡해 보인다). 그래서 뜻이 분명한 꼴로만 적는다.

### 5. 따옴표로 시작하는 쪽을 막던 규칙을 뺐다
이 책은 쪽이 대사로 시작하는 일이 흔하다 — `"내가 먼저야." "아니, 나야."` 가 그래서 막혔다.

### 6. 그 뒤로는 기계가 지킨다
`FilterVsStoryTest` 가 **원고 290쪽과 조각 대사 234줄을 전부** 필터에 통과시켜 본다.
우리 원고가 걸리면 그건 필터 버그다 — 같은 결로 쓴 생성 문장도 다 막히기 때문이다.
