## 이 측정으로 고친 것

1. **지시문에서 "한 문장만" 을 뺐다.** 원고의 한 쪽은 대개 두 문장인데 "한 문장" 을 요구하니
   모델이 둘을 **쉼표로 이어 붙여** 길게 늘였다 — 그림책의 짧게 끊는 결이 통째로 사라졌다.
   문장 수를 원문에 맞추고 글자 수에 천장을 주자 마침표로 끊어 쓰기 시작했다.
2. **길이 천장을 좁혔다.** 원문의 2배까지 봐 주던 것을 `원문+20자` 로 줄였다.
3. **"문장이 늘면 막는다" 는 규칙은 넣었다가 뺐다.** 처음 측정에서 막힌 4줄이 전부 그거였는데,
   넷 다 모델이 **긴 문장을 짧게 쪼갠 것**이었다. 그림책에서는 그게 더 나은 글이다.
